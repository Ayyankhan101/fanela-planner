\subsection*{Alternatives considered (for the record)}

\begin{itemize}
  \item \textbf{Buy off-the-shelf (PrintVis $\approx$ \$130--150/user/month, Odoo
        print add-ons)} -- rejected: Fanela's own rules would need paid customisation
        anyway, plus per-seat cost and lock-in; revisit only if the business wants a
        full ERP.
  \item \textbf{Microservices} -- rejected: industry consensus puts the switch above
        $\sim$30 engineers; modular monolith kept, extraction path stays open.
  \item \textbf{Laravel / Django instead of Next.js} -- equally valid only if the
        implementing team is PHP/Python-native; TypeScript stack kept.
  \item \textbf{Serverless cloud hosting} -- rejected: usage bills grow, data stays
        with a third party; one VPS is enough for one factory.
\end{itemize}

\subsection*{Open questions for this meeting}

\begin{enumerate}
  \item \textbf{Permission matrix sign-off} -- especially: who exactly sees costs in
        reports (Director only?), who holds the ``authorised commercial'' flag for
        selling prices, and how far Office can set planned dispatch details.
  \item \textbf{Final department list} -- print, embroidery, warehouse, screens,
        dispatch, packing: is anything missing or misnamed?
  \item \textbf{Readiness verification} -- confirm the White/Amber/Green counting rules
        against how the prototype actually behaves (especially blank screens).
  \item \textbf{Attachments} -- is 25 MB per file right, and who may download which
        file types?
  \item \textbf{Backups} -- retention period (30 days proposed) and where the off-server
        copy should live.
  \item \textbf{DPD and Xero timing} -- confirm both are Phase 4, or pull one forward.
  \item \textbf{Session behaviour on shared terminals} -- proposed 2-hour idle timeout
        (12-hour absolute cap stays; an earlier 12/12 pairing made the idle rule dead
        code). Confirm 2 hours, or add a quick PIN re-lock screen as well?
  \item \textbf{Data inventory} -- confirm that only one machine holds prototype data
        and identify the definitive backup file to migrate from.
\end{enumerate}
